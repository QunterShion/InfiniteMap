## 问题排查指南

### 问题：日志面板不显示

**排查步骤：**
1. 检查 Console 是否有 JavaScript 错误
2. 确认 `agent-session-log` 指令已注册
3. 检查 `ng-if="minder"` 条件是否满足
4. 验证 CSS 是否正确加载

### 问题：事件不更新

**排查步骤：**
1. 打开 Console，查看 `agent-session-event` 事件是否触发
2. 检查 executionId 是否匹配
3. 验证事件类型是否在 switch 分支中处理
4. 检查 `$apply()` 是否被调用

### 问题：增量显示卡顿

**排查步骤：**
1. 检查节流时间（当前 100ms）
2. 查看 Performance 面板的 FPS
3. 确认没有内存泄漏
4. 验证事件去重机制正常工作
